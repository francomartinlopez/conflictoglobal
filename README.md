# Conflicto Global — Monitor de Conflictos

Monitor de los principales conflictos militares y paramilitares del mundo: mapas con línea de tiempo, víctimas y daños por bando, cronología histórica, análisis y alertas.

Sitio estático (HTML, CSS y JavaScript sin dependencias externas). Se publica con GitHub Pages desde la rama `main`.

## Estructura
- `index.html`, `css/`, `js/`: interfaz.
- `data/`: datos de los conflictos, análisis, víctimas, series, control territorial y mapa del frente de Ucrania.
- `vendor/`: d3-geo, d3-array y topojson-client.
